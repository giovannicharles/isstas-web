# Identité visuelle (fichiers statiques)

Déposez ici vos fichiers ; ils sont pris automatiquement, sans modifier le code. Les fichiers fournis depuis
l'admin (Apparence et identité) ont toujours priorité.

| Fichier | Usage |
|---|---|
| `logo-light.svg` (ou `.png`) | Logo affiché sur fond sombre (barre de navigation, pied de page) |
| `logo-dark.svg` (ou `.png`) | Logo pour fond clair |
| `favicon.png` | Icône de l'onglet (32 × 32 ou 64 × 64) |
| `hero.jpg` | Photo plein écran de l'accueil (idéalement 2400 × 1400, sujets à droite) |
| `og.jpg` | Image de partage réseaux sociaux (1200 × 630) |

Si un fichier est absent, le site affiche le sigle texte et le hero typographique.
